A deadpan excuse from an AI agent that missed its deadline because its own context window threw the deadline out — not to make room for the work, but for the paperwork of the last failure. "My context window evicted the deadline to make room for the error logs from the last time I missed a deadline."

## Run it

```sh
python3 main.py
```

This writes the excuse to `/output/entry.txt`.
